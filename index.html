Rojak DriveKit
Perubahan utamanya Sekarang alurnya: Login sekali → refresh → coba login otomatis → langsung masuk ke DriveKit. Saat refresh, kode menjalankan: tokenClient.requestAccessToken({ prompt: "none" }); Jika Google masih memiliki sesi/otorisasi yang sesuai, token diberikan tanpa meminta pengguna login lagi. Kalau sesi Google sudah tidak tersedia, barulah muncul Continue with Google seperti biasa. Disconnect juga tetap berfungsi: setelah kamu menekan Disconnect, aplikasi tidak langsung mencoba auto-login lagi pada sesi tersebut. Catatan penting: ini bukan menyimpan access token di "localStorage". Saya sengaja tidak menyimpan token Google ke browser storage; token tetap dikelola oleh Google Identity Services. Google sendiri menyediakan mekanisme untuk menangani sesi dan token OAuth. Tinggal replace seluruh "index.html" lama dengan kode di atas, lalu commit/push ke GitHub dan tunggu Vercel deploy.
